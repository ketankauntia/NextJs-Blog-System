# Product design system

Use neutral paper and ink, a small cobalt accent, generous whitespace and real content. Product typography uses Geist; the landing headline uses Instrument Serif. Publication typography remains configurable in Studio.

- Content width: 74rem. Page gutters: 24px desktop, 20px mobile.
- Use a 4px spacing base, with 24/32px component gaps and 80/112px section spacing.
- Use existing shared UI components, design tokens and header/footer patterns.
- Surfaces are white/subtle gray in light mode and neutral near-black in dark mode. Cobalt indicates interaction and selected state.
- Corners: 8px controls, 12px content surfaces, 16px major product surfaces. Avoid unnecessary nested cards.
- Use quiet borders and restrained shadows. Prefer short color/opacity/transform transitions; respect reduced motion.
- Write concrete, concise copy. Avoid duplicate actions and unverified capability claims.
- Preserve semantic headings, labels, keyboard navigation, visible focus, responsive wrapping and touch targets.
- Use code-native UI and typographic post covers when no image is provided. Keep images and Markdown portable.
- Preserve the content parser, SEO fields, editor behavior and server-enforced production mutation restrictions.

Review desktop and narrow layouts, keyboard access, themes and primary interactions for changes to the user interface. Run the checks appropriate to the changed behavior. Preserve existing content and unrelated user work.

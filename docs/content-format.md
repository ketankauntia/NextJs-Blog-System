# Content format

Posts are markdown files in `content/posts/<slug>.md`. The filename becomes the URL slug, so `content/posts/hello-world.md` is served at `/blog/post/hello-world`.

The parser lives in [`lib/blog/parse.ts`](../lib/blog/parse.ts) and is shared with the authoring studio's live preview, so what you see while editing is what the page renders.

## Frontmatter

| Field | Required | Notes |
| --- | --- | --- |
| `title` | yes | Post title and H1. Keep it under 60 characters or the brand suffix is dropped. |
| `description` | yes | Meta description and card excerpt. Aim for 115–158 characters. |
| `category` | yes | Free text. Category pages are derived from the set of values in use. |
| `tags` | no | YAML array, e.g. `[databases, performance]`. |
| `publishedAt` | yes | `YYYY-MM-DD` or a full ISO timestamp. Future dates stay hidden in production until that date. |
| `updatedAt` | no | Shown in the byline and used for `dateModified` and sitemap `lastmod`. |
| `author` | no | Author slug from `lib/blog/authors.ts`. Defaults to the first author listed. |
| `featured` | no | `true` puts the post in the hero slot on the home page and the archive. |
| `draft` | no | Visible in development, excluded from production listings, sitemap, RSS and llms.txt. |
| `cornerstone` | no | Marks pillar content: higher sitemap priority and stricter editor scoring. |
| `noindex` | no | Excluded from the sitemap and emits a robots noindex. |
| `canonical` | no | Overrides the self-referencing canonical URL. |
| `coverTone` | no | Gradient used when there is no cover image: `primary`, `chart-2`, `chart-3` or `chart-5`. |
| `coverImage` | no | Visible 16:9 cover. 1600×900. |
| `coverAlt` | no | Describes the cover for screen readers. Do not stuff keywords. |
| `ogImage` | no | Social card override at 1200×630. Falls back to `coverImage`, then to the card generated by `opengraph-image.tsx`. |
| `tldr` | yes | Answer-first summary rendered near the top and used as `abstract` in JSON-LD. |
| `keyphrase` | no | Focus phrase for the editor's SEO checks. Never rendered. |
| `keyTakeaways` | no | List of bullets rendered under the TL;DR. |
| `faqs` | no | List of `{q, a}` entries. Rendered as an accordion and emitted as `FAQPage` schema. |

Reading time is computed from the body at roughly 200 words per minute.

> **Quote any value containing a colon followed by a space.** YAML reads `Boring is the feature: it works` as a mapping, not a string, and the build fails at render time rather than at parse time.

Run `npm run audit:content` to check every post against the length and completeness rules before building.

## Body syntax

The parser accepts a constrained subset of markdown plus two directives. Anything outside this list renders as a paragraph.

| Syntax | Renders as |
| --- | --- |
| `## Heading` | Section boundary and table-of-contents entry |
| `#`, `###`–`######` | Heading block inside the current section |
| Blank-line separated text | Paragraph |
| `- item` / `1. item` | Unordered / ordered list |
| `- [ ] item` / `- [x] item` | Task list |
| GFM pipe table | Table |
| `> quote` | Blockquote. A final `> — Name` line becomes the attribution |
| ` ```lang ` fenced block | Code block |
| `![alt](/blog/slug/img.webp "Caption")` | Image with optional caption |
| `---`, `***` or `___` alone on a line | Divider |
| `:::stat VALUE \| label` | Stat callout |
| `:::callout Title` … `:::` | Callout box |

Inline formatting inside any block: `**bold**`, `*italic*`, `~~strike~~`, `==highlight==`, `` `code` `` and `[links](https://example.com)`. External links get `target="_blank"` and `rel="noreferrer"` automatically.

Only `##` creates a section. Content before the first `##` becomes a heading-less intro section, which is why the opening paragraphs render normally without appearing in the table of contents.

## Images

Keep each post's assets in `public/blog/<post-slug>/` with lowercase descriptive filenames.

- **Cover** — `<slug>-cover.webp`, 1600×900. Keep the subject central; the same image is cropped for cards and for the wide article hero.
- **Social** — `<slug>-og.jpg`, 1200×630. JPEG for maximum compatibility across social crawlers. Omit it and the site generates a card from the title instead.
- **Body** — 1400×788 WebP is a good default. Always write real alt text, and add a caption when the image carries information the prose does not.

Do not bake the title, category or logo into cover art. The page renders that text in HTML, where it stays selectable, translatable and crisp at any density.

## The authoring studio

`/dashboard` is available in development only — its layout returns a 404 when `NODE_ENV` is `production`, and its write endpoints touch the filesystem, which is not something a deployed site should do.

- `/dashboard` — every post with word count, SEO score, status and the metadata that drives it
- `/dashboard/editor` — rich-text editor writing the same markdown format, with live SEO and readability checks
- `/dashboard/preview` — try each listing and post template against real content
- `/dashboard/settings` — pick the active templates, written to `content/settings.json`

Everything it writes is a plain file in `content/`. The repository stays the source of truth, so posts are reviewable in a pull request like any other change.
